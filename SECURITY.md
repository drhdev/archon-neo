# Security policy

Archon NEO is a static web app without accounts, server-side logic or data collection. Game progress and settings are stored only in the player's browser (`localStorage`).

## Reporting a vulnerability

Please report security issues privately via [GitHub security advisories](https://github.com/drhdev/archon-neo/security/advisories/new) instead of public issues. You can expect a first response within a few days.

## Supported versions

Only the latest release on `main` receives fixes.
